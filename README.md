# ⚔️ Game of Thrones — Fan Website

A fan-made website inspired by the epic fantasy world of *Game of Thrones*. Explore the legendary houses, iconic characters, kingdoms, and the world of Westeros through an immersive web experience.

## 🌟 Features

- 🐉 **Great Houses** — Discover the noble houses of Westeros.
- 👑 **Characters** — Explore iconic characters and their stories.
- 🗺️ **World of Westeros** — Learn about the kingdoms and locations.
- ⚔️ **Immersive UI** — A fantasy-inspired design with a medieval atmosphere.
- 📱 **Responsive Design** — Designed to work across desktop and mobile devices.
- ✨ **Interactive Experience** — Smooth interactions and engaging visual elements.
